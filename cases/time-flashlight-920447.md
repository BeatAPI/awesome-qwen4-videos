## Creator-published prompt

```text
请设计并实现一个令人过目不忘的交互式网页作品：

《时间不是进度条，是一把手电筒》
TIME IS A FLASHLIGHT
你是一位交互艺术家、创意前端工程师和电影美术指导。请直接交付可以运行的完整作品，不要只给方案、示意图或代码片段。

【核心体验】

浏览器里是一座被封存在玻璃展柜中的微缩城市。

展柜之外漆黑安静，桌面上有磨损的黄铜铭牌、年代刻度和一只机械调节旋钮。城市内部有钟楼、电车轨道、车站、街巷、树木，以及几栋可以辨认的建筑。

用户移动鼠标，相当于移动一束“时间手电筒”。

光束之外，是荒废已久的城市。
光束之内，是用户选择的年代。

同一座钟楼，可以一半是锈蚀废墟，另一半仍灯火通明；同一条街道，可以一侧长满植物，另一侧有电车经过。年代之间必须空间对齐，不能通过切换两张背景图假装实现。
第一眼让人想停下来，第一次移动鼠标就让人理解玩法，继续探索则不断发现细节。

【视觉方向】

整体像一件真实存在的博物馆互动装置，具有微缩模型摄影的质感。

采用等距或轻透视俯视构图，让建筑、街道与时间切面容易辨认。城市占据主要画面，界面控件像装置上的实体零件。

视觉元素：

深炭黑环境、暖象牙白文字、氧化铜、少量琥珀色灯光。

建筑有明确体积、遮挡关系、接触阴影和细小窗户。
玻璃边缘有克制的反光，不能盖住主体。
废墟有断裂结构、植被侵入、熄灭的路灯。
繁华时代有暖窗、电车、少量移动人影。
尚未建成的时代呈现测绘线、地基、建筑轮廓和手写标注。
不要常规首页、卡片网格、后台布局、紫色渐变、满屏霓虹，也不要用大量文字解释创意。字体、留白、按钮和细节应与这件装置属于同一个世界。
【必须实现的交互】

时间光束
鼠标移动控制光束位置，边缘具有柔和但清晰的年代过渡。光束应揭示另一个年代真实存在的建筑和动态内容，不只是提亮、调色或模糊。

鼠标滚轮调整光束半径；提供可见的替代控件。光束内的微小尘埃和边缘折射可以增加质感，但不能影响辨认。

机械年代旋钮
用户拖动旋钮，在三个年代之间连续调整：
1920：尚未建成的城市，蓝图、地基和施工结构。

1980：繁华的城市，电车、亮灯的车站和街道。

2080：被遗忘的城市，植物覆盖、结构残缺。
年代变化必须体现在场景本身。允许用阶段插值与交叉过渡实现，但建筑位置、道路和地标必须保持一致。
旋钮要有指针、刻度、拖动反馈及键盘操作。数字读数与画面状态实时同步。
固定时间窗口
点击“钉住这一刻”，将当前光束保存为一个固定时间窗口，保留它自己的年代和半径。
最多保留三个窗口。用户可以移动、关闭这些窗口，并继续移动手中的光束。

每个窗口必须保持独立状态。窗口重叠时使用明确且稳定的显示优先级，不要闪烁或随机变化。

让用户能够同时看到：蓝图中的钟楼、繁华时代的车站、废墟中的街区。

城市里的小秘密
设计三个可以通过探索发现的细节，例如：
废墟车站的长椅，在过去坐着一个等车的人。

倒塌的钟楼，在过去会准点摆动钟摆。

一棵占据街道的大树，在早期只是路边的一株树苗。

发现时仅出现一句克制的短文案，避免弹窗打断体验。命中检测必须对应用户实际看到的年代与位置，不能点击空白处也触发。

自动演示
提供“让时间自己走一会儿”按钮，启动约 20 秒的编排演示：光束移动、年代变化、展示不同地标，最后回到可操作状态。
用户随时操作都应立即接管，不能与演示争抢控制权。
【开场与细节】
打开后立即看到完成度高的城市，不要用加载动画拖延。
开场用一次短暂的光束掠过，自然展示“同一建筑的两个年代”，随后显示一句提示：

“移动光，看看这里曾经是什么样子。”

界面文案使用中文，英文仅作少量辅助标识。
加入可关闭的环境音，通过用户首次交互后启动；可以用 Web Audio 程序化生成轻微机械声、电车铃声和空间氛围，不依赖外部音频文件。

【技术要求】

交付一个完整、自包含的 HTML 文件，包含全部 CSS 和 JavaScript。

场景素材用代码生成，不依赖外部图片、视频、模型或付费资源。

可选择 Canvas、SVG、WebGL 或组合方案，以最终效果和交互稳定性为准。

城市各年代共享同一套空间坐标与地标数据。

不能把整个作品做成预渲染视频，也不能用静态插画代替核心交互。

正确处理高分屏、窗口缩放、指针离开、拖动取消和坐标换算。

桌面端优先，同时支持手机触摸移动光束，以及通过控件调节半径与年代。

限制粒子与绘制成本，避免不断累积动画循环和事件监听。
尊重 prefers-reduced-motion，并提供暂停动态效果的入口。
所有可见按钮必须真实可用。
【验收标准】
我会亲自测试以下行为：
移动光束，检查同一栋建筑是否准确对齐。
改变年代，检查城市内容是否真实变化。
固定三个不同年代的窗口，检查它们是否保留独立状态。
移动并关闭窗口，检查是否出现残影或错误遮挡。
在自动演示中主动拖动旋钮，检查能否立即接管。
缩放窗口，检查光束和交互热点是否仍然准确。
请把主要精力放在城市的视觉完成度、时间切面的惊奇感和交互的完整性上。宁可精心完成一个街区，也不要堆砌一大片简陋方块。
最终交付的是一件可以亲手探索的互动艺术作品。现在直接实现。
```
